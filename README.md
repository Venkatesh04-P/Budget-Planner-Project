# Budget Planner with Charts

A responsive monthly budget planner built with HTML5, CSS3, JavaScript, Chart.js, and LocalStorage.

## Features
- Set a budget for each category
- Add and delete expenses
- Automatically aggregate expenses by category
- Compare budget vs actual spending using a bar chart
- Over-budget warning indicator
- Total budget, total spent, remaining amount, and usage percentage
- Data persistence using browser LocalStorage
- Responsive design for desktop and mobile

## How to Run
1. Download or clone the project.
2. Open `index.html` in a browser.
3. Add category budgets and expenses.
4. The chart and summary update automatically.

Internet is required when opening the page if Chart.js is not cached, because Chart.js is loaded from its CDN.

## Technologies
HTML5, CSS3, JavaScript, Chart.js, LocalStorage.
